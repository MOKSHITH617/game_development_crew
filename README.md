# AI Game Development Crew

An AI-powered multi-agent game development system built using CrewAI and Google's Gemini model. The application automates the complete game creation workflow, from game design to code generation and quality review.

## Features

* Multi-agent AI architecture using CrewAI
* Automated game design document generation
* Python Pygame code generation
* AI-powered code review and quality assurance
* Web search integration using Serper API
* End-to-end game development pipeline
* Automatic deployment support using Pygbag and Ngrok

## Tech Stack

* Python
* CrewAI
* Gemini 2.5 Flash
* Pygame
* Serper API
* Google Colab
* Pygbag
* Ngrok

## AI Agents

### Creative Game Designer

Generates game concepts, mechanics, controls, objectives, and gameplay design documents from user ideas.

### Senior Python Game Developer

Creates complete and runnable Pygame implementations based on the generated design specifications.

### QA Engineer & Code Reviewer

Reviews generated code, identifies issues, improves gameplay quality, and produces the final polished version.

## Workflow

1. User provides a game idea.
2. Game Designer Agent creates a detailed game design document.
3. Developer Agent generates complete Pygame source code.
4. QA Agent reviews and improves the generated game.
5. Final game is prepared for deployment and execution.
